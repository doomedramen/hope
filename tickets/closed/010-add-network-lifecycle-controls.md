## Problem

Infrastructure exposes `Add network` but no visible way to edit or delete an existing network.

## Context

The hosted Infrastructure page lists the configured `192.168.1.0/24` network and offers scope calculation and scan controls, but no network lifecycle action. Network deletion or correction therefore cannot be performed from the UI.
