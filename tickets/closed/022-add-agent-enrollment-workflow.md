## Problem

The empty Agents page tells the operator to “Enroll a Linux agent to collect host inventory” but provides no enrollment action, command, download, token, or documentation link. A user cannot proceed from the product to enroll the first agent.

## Context

With zero enrolled agents, the page exposes only Refresh, Search agents, and the empty-state message. Add an actionable enrollment flow or link to the required installation and registration instructions.
