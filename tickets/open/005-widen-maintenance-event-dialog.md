## Problem

The Create maintenance event dialog is too narrow. Its content overflows and is clipped instead of remaining fully visible or usable.

## Context

The issue was observed in the hosted maintenance page while the Create maintenance event dialog was open. The dialog should be widened or its layout should reflow so all form content remains accessible at the current viewport width.
